# Convention

> Thư mục này ghi cách viết code để code dễ đọc, dễ sửa và dễ nâng cấp. Người viết code và AI agent đọc file chung cộng
> với file của mảng mình đang sửa. TL giữ khung, code owner của từng mảng giữ file của mảng đó.

| File | Áp dụng cho |
|---|---|
| [`general.md`](general.md) | Mọi code trong repo |
| [`backend.md`](backend.md) | Backend |
| [`frontend.md`](frontend.md) | Frontend |
| [`ai.md`](ai.md) | Prompt, agent, tool, và code train model |

Luật chung có sẵn từ template. Phần riêng của từng stack được chốt ở GĐ2, sau khi đã có ADR chọn stack.
