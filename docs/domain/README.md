# Domain

> BA giữ thư mục này. Đây là nguồn sự thật về nghiệp vụ: code, prompt và eval đều lấy luật từ đây, không viết lại luật
> ở chỗ khác.

| File | Nội dung |
|---|---|
| [`glossary.md`](glossary.md) | Thuật ngữ, và tên chuẩn trong code của trạng thái, trường, tool |
| [`business-rules.md`](business-rules.md) | Luật nghiệp vụ dạng bảng, mỗi luật một mã |
| [`data-model.md`](data-model.md) | Thực thể, quan hệ, trạng thái, trường chứa PII |
| [`edge-cases.md`](edge-cases.md) | Ca biên và cách xử lý đúng |

Tên mà máy đọc (trạng thái, trường, tool) viết tiếng Anh `snake_case` và chỉ định nghĩa ở `glossary.md`. File khác dùng
đúng tên đó.
